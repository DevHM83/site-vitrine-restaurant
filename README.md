## 📝 Présentation

**Saveurs du Monde** est un **site vitrine responsive** mettant en avant 6 plats emblématiques de cuisines internationales :

- Italie : Lasagnes à la bolognaise
- Algérie : Couscous royal
- Sénégal : Thiéboudienne
- Mexique : Tacos al pastor
- Inde : Butter chicken
- Japon : Ramen tonkotsu

**Objectifs** :

- Pratiquer **HTML5, CSS3, JavaScript vanilla**.
- Créer un design **responsive** (mobile, tablette, desktop).
- Intégrer une **galerie interactive** et un **formulaire de contact**.
